# 投影原理图

实例的「投影」标签页能列出、3D 预览、转换 Litematica（`.litematic`）、Sponge（`.schem`，WorldEdit / FAWE）和原版结构文件（`.nbt`）。这篇讲解析层怎么防不可信文件、转换能做到哪一步、前后端怎么分工，以及 3D 预览为什么这样做。

## 分工

| 层 | 做什么 |
| --- | --- |
| `aether-schematic` | 只管字节：NBT 读写、三种格式的读写、格式转换。不读写文件、不联网 |
| `aether-storage::schematic_files` | 按纯文件名读一个投影（有大小上限）；把转换结果存成新文件（独占创建，绝不覆盖） |
| `src-tauri::commands::schematics` | 把解析结果整理成预览用的紧凑结构；调用转换；前端传的只有实例 ID、纯文件名、格式标签、数据版本号 |
| 前端 `lib/schematic/*` | 建网格、指方块、相机、帧预算——全是纯函数，不碰 DOM，能单测 |

## 不可信输入

投影文件是别人发来的。解析层对它的每一部分都设了上限，越界是错误，不是崩溃，也不会按文件头里写的长度去分配内存：

- NBT 嵌套最深 64 层；一个文件最多 400 万个值；数组、列表、字符串声明的长度必须不超过剩余字节数。
- gzip 解压后最多 96 MiB（`take` 限读，压缩炸弹在上限处停下）；压缩文件本身最多 64 MiB。
- 方块总数（包围盒，含空气）最多 800 万，单边最多 4096，调色板最多 65536 项，方块实体最多 20 万个。800 万个方块在内存里是 32 MB，在 Minecraft 官方最低配置的机器上也撑得住。
- 文件里的内容从不被执行；方块实体的数据只被当作文本显示。

## 转换

**格式转换是精确的**：同样的方块、方块状态和方块实体，换一个容器写出来（三种互转，测试覆盖所有 9 种组合）。Litematica 自己的放置设置、区域列表不保留，转换时会提示。

**换 Minecraft 版本不是完整升级。** 游戏自己的 DataFixerUpper 不在这里，所以只做**确定无疑**的几件事，其余原样保留并在结果里列成警告：

- 方块改名：目前只有 1.20.3 的 `grass` → `short_grass`（升级和降级都做）。这张表故意很短；1.13「扁平化」之类需要游戏完整的数据表，不碰。
- 1.20.5 起容器里物品的格式：`Count`（字节）↔ `count`（整数）。`tag` / `components` 两边格式不同，无法可靠互转，**会被丢掉并提示**；容器里再套容器（箱子里的潜影盒）不转换，也会提示。
- 1.20 起告示牌文字格式变了：跨过这条线时提示「可能要重新写字」。
- 总会提示：方块没有对照目标版本的方块表检查，目标版本里不存在的方块加载不出来。
- 源文件没写数据版本号时，只改版本号，并说明。

结果存成同一个 `schematics/` 里的新文件（`名字 (converted).格式`，重名就加序号），原文件不动。

## 3D 预览

纯色方块（启动器不带也不读取 Mojang 的纹理），鼠标指到方块时显示坐标、ID、方块状态、方块实体的 NBT 和容器内容。

**帧预算**：目标是跟着显示器的刷新率走，不是固定 60。`requestAnimationFrame` 的间隔就是刷新周期，量出来（吸附到 60/120/144/165/240 等常见值）就得到每帧预算：60 Hz 约 16.7 ms，144 Hz 约 6.9 ms，240 Hz 约 4.2 ms。

- 每帧里启动器自己做的事有上限：只画；建网格按「时间片」做，每帧最多预算的约 12%（上限 3 ms），上一帧已经吃紧就一点都不做。不用 Web Worker——单核机器上它和渲染抢同一个核，反而造成掉帧。
- 网格按 16×16×16 分块、贪心合并同色相邻面，一整面墙只需要两个三角形；离相机近的块先建；每帧最多往 GPU 上传一块。
- 画质自适应：连续吃紧就先降渲染分辨率（最低 50%），再缩可见距离；连续很久都宽裕才慢慢升回来。一次长帧不会触发降级。
- 相机不动、没有新网格时不重绘；指方块用体素步进（开销只和光线穿过的格子数有关，和方块总数无关），只在视角或鼠标变化时做一次，提示框只在指到的方块变化时更新。
- F3 显示刷新率、预算、帧间隔和启动器耗时的 95 分位、掉帧数（帧间隔超过预算 1.5 倍）、当前画质档。

**不能保证的**：「一帧都不掉」。操作系统调度、垃圾回收、别的程序抢 CPU/GPU 都会造成偶发的长帧，浏览器也不能画得比显示器刷新得更快（200 帧需要 200 Hz 的显示器）。这里做的是让自己的部分永远在预算之内、慢了先降画质，并把掉帧如实报告出来。没有在真实的最低配置机器（Minecraft 官方最低配置的集成显卡）上量过。

## 待定

- **贴图。** 现在是纯色。用已安装游戏版本的 jar 里的贴图可以画得更像，但要读取并解包 Mojang 的资源，需要先定怎么缓存、怎么处理版权和资源包。
- **非整块的形状。** 台阶、楼梯、栅栏、半砖现在都画成整块。
- **更多格式。** 旧的 `.schematic`（MCEdit）会被识别并提示先用 WorldEdit 转；不读。
- **完整的版本升级。** 需要游戏的数据修复表，见上面「转换」。
- **实体。** 投影里的实体（盔甲架、画）不读也不画。
